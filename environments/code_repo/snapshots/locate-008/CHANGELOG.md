# `ratelimit` 网关准入路径变更记录

只记录会影响准入结论的改动；纯文档/看板改动单列。

- 2025-06-02 **#3620** 令牌桶参数定为 `BUCKET_CAPACITY=14`、`REFILL_INTERVAL_S=4`；
  回填改为**连续回填**（按经过时间 / 间隔计，不再按整秒截断）。`CAP_PER_EPOCH` 同期定为 8。
- 2025-08-14 **#3980** epoch 序号统一为整除 `at // EPOCH_S`。
- 2025-09-22 **#4180** `batch` 租户在 epoch 配额分配中按 2 倍权重计入。
- 2025-11-20 **#4455** `metrics.render` 的输出标签 `scope` 重命名（仅可观测性，不参与准入判断）。
- 2025-12-03 **#4412** `allocator.fair_share` 的基础配额由 `math.floor` 改为 `math.ceil`：
  此前小权重租户在余数分配之前就被整体截断为 0，`web`/`mobile` 长期拿不到额度。
  副作用：各租户基础配额之和**可以超过** `CAP_PER_EPOCH`（需求封顶只压单个租户，不回收余量）。
