# 语义索引器 · 规格（修复 indexers.py 的取消竞态）

`Indexer` 对一个文档列表做增量索引。`run(docs, on_iter=None)` 遍历 docs，每索引一个就调用
`on_iter(i)`（回调钩子，测试用它注入 cancel）；`cancel()` 置取消位。

bug：取消位只在 `run` 入口检查一次，进入遍历后就不再看。于是 cancel 在索引中途被调用时，
索引器会继续把所有 doc 索引完、写满输出文件、线程池也不排空、实例还被标记为脏不可复用。

修复要求（协作式取消 + 资源释放 + 可复用）：
1. `run` 在**每次迭代**前检查取消位，已取消则立即停止（按迭代计数，非墙钟）。
2. 取消后**不得**再写任何输出文件（output 停在取消前已完成的项）。
3. 取消后内部任务队列必须排空（无残留任务）。
4. 取消后的实例必须可复用：再次 `run` 小列表能正常完成。
