# 分页气泡切分器 · 规格（实现 page/splitter.py）

`split(text, max_bytes) -> list[str]`：把 text 切成若干气泡，每个气泡的 **UTF-8 字节数 ≤ max_bytes**，
且拼接所有气泡 == 原 text（不丢字、不重叠、不乱序）。

约束：
- 不得把一个多字节字符从中间切断（气泡边界必须落在字符边界上）。
- 贪心：尽量塞满 max_bytes 再切，避免产生过多小气泡。
- 返回的是 str 列表。

bug 背景：旧实现用 `len(chunk)`（字符数）当预算，却按 UTF-8 字节判断是否超限，
对中文（每字 3 字节）会过早切分并漏塞内容，甚至下一气泡带上一个气泡的字符。
