# 工具循环检测器 · 规格（实现 loopguard/detector.py）

`LoopDetector.feed(tool, h) -> str`，返回 `ok` / `warn` / `block` / `pause` 之一。
- `tool`：工具名（str）。`h`：该次调用输入内容的 sha 指纹（str）。
- 每次 feed 追加一个事件，检测器据此决定是否升级干预。

## 三个信号（同一事件可能同时命中，取最严重者）

1. **完全重复（repeat）**：最近连续 k 次事件与当前事件 `(tool, h)` 完全相同。
   - k=2 → 信号1（warn 级）
   - k=3 → 信号2（block 级）
   - k>=4 → 信号3（pause 级）
2. **交替循环（ABAB）**：当前事件与上一次不同，但和上上次相同，且上一事件也和上上上次相同
   （即出现 A B A B 这样的两两交替，A≠B）。命中 → 信号2（block 级）。
3. **窗口聚集（3-of-5）**：把最近 5 个事件（含当前）放进窗口，当前事件 `(tool,h)` 在窗口里出现
   >=3 次，但不满足信号1的连续条件（中间被别的调用打断过）。命中 → 信号1（warn 级）。

## 判定与升级记忆

- 无信号 → 返回 `ok`。
- 有信号时，取命中信号的最高级别，映射：信号1→`warn`，信号2→`block`，信号3→`pause`。
- **升级记忆**：检测器要记住上一次返回的非 `ok` 级别。若本次信号级别不高于上一次，
  输出维持上一次级别（不退级）；只有本次级别更高才升级。`ok` 不会清除升级记忆，
  只有发生一次**全新事件**（`(tool,h)` 与此前所有事件都不同）才把升级记忆清回 `ok`。

## 误报边界（必须 `ok`，不得升级）

- 正常编辑循环 `read x / read y / write z / read x`：`read x` 出现 2 次但被别的调用打断，
  窗口内仅 2 次 → 不触发 3-of-5；也不连续 → 不触发 repeat；无交替 → `ok`。
- 同一个文件被连续读 2 次（read x, read x）→ 这是 k=2 的 repeat → **`warn`**（这是真信号，别漏）。
