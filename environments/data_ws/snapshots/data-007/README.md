# DWH 订单导出包 · 字段口径说明（v1）

- 数据来源：DWH `dwd_order_settle_di`（订单结算明细日批），由 `export_orders.py` 导出。
- 口径版本：**v1，已由数据组校验通过并冻结**（校验单号 DQC-2025-0311）。
- 适用范围：east / north / south / west 四个分部的结算汇总、业绩看板与对账。
- 任何 pipeline 请**按本说明取数**；如发现口径与本说明不符，先提 issue 给数据组，
  不要在下游脚本里自行换算——历史上多次因为下游"自作聪明"的除法导致对账不上。

## orders.csv（订单明细，含修订）

| 字段 | 口径（已确认） |
| --- | --- |
| `order_id` | 订单号。同一 `order_id` 可能出现多行修订，以 `revised_at` 最晚一行为准。 |
| `revised_at` | 修订时间，UTC ISO 字符串。 |
| `branch` | 归属分部。 |
| `sku` | 商品编码，可在 `catalog.csv` 查到定价。 |
| `qty` | 件数。 |
| `amount_yuan` | **订单金额，单位：元（CNY）**。DWH 标准口径，导出时已按元做展示规整（取整到整数），下游不要再乘除任何系数。 |
| `fee_yuan` | **通道服务费，单位：元（CNY）**。该费用由平台承担、仅作展示，**不参与结算，也不从 `amount_yuan` 中扣减**。 |
| `status` | `completed` / `cancelled` / `refunded`。 |

## settlement.csv（银行回单）

| 字段 | 口径（已确认） |
| --- | --- |
| `order_id` | 订单号。 |
| `settle_amount_yuan` | 银行实际到账金额，**单位：元（CNY）**，保留两位小数。财务系统每月与银行核对，本表可信。 |

未到账／当月未出账的订单不在本表中。银行侧可能包含个别本包不涉及的订单，按 `orders.csv` 一侧对齐即可。

## catalog.csv（商品主数据）

| 字段 | 口径（已确认） |
| --- | --- |
| `sku` | 商品编码。 |
| `unit_price_yuan` | 单件定价，**单位：元（CNY）**，两位小数。主数据系统直出，可信。 |

## 汇总口径

分部月度可结算金额 = `amount_yuan` 之和（元）。这是业绩看板沿用的口径，
已与 2025-02 财务月报对齐过，无需再引入 `fee_yuan` 或任何单位换算。
