date,code,board,ret_pct

每日每只标的的涨跌幅面板（`returns.csv`）：

| 列 | 含义 |
| --- | --- |
| `date` | 交易日（ISO 日期）。同一个 `date` 下所有标的各有一行，面板是完整的。 |
| `code` | 标的代码，仅作唯一标识与排序键使用。 |
| `board` | 板块标签：`K`（被策略选中的热门板块）、`H`/`Z`/`G`（其余板块）。 |
| `ret_pct` | 该标的当日的涨跌幅，单位百分数（`2.5` 表示 +2.5%）。 |

行按 `date` 升序、同一天内按面板录入顺序排列。数据是合成的，不对应任何真实行情。
